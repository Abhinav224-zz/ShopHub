ShopHub – Sign Up / Login System with MongoDB + n8n Workflow

A simple full-stack authentication system built with React, Node.js, and MongoDB, with an n8n workflow trigger on every new signup.
Features

Clean and simple Sign Up and Login UI

Secure user credential storage using MongoDB


Redirect to a Dashboard after login

n8n Webhook Integration → triggers on each new signup

Example uses: send welcome email, store data in Google Sheet.
